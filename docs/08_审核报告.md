# pro 模型审核报告（2026-11-21）

对项目做了一次独立审核：三个并行 reviewer（模型/生物学、健壮性/边界、架构/一致性）+ 主模型通读核心代码，
交叉验证后逐条修复。本报告记录结论、修复与仍欠的债。

## 一、方法论

- 三个 reviewer 各自只读代码、不改文件，按严重度给「文件:行号 + 触发条件 + 建议」；
- 主模型独立通读 models/sequence/design/mapping/validate/io/report/thermo，形成第二份判断；
- 所有"实锤"项都在**修复前**用最小复现脚本跑出过错误，再修、再加回归测试（`tests/test_pro_audit.py`）。

## 三、架构收敛（reviewer-3 M2）

三份参数来源收敛为一份：

- 删除 `params/project.params.json`、`params/design_config.yaml`（旧模板）；
- `tools/check_params.py` 重写为包装 `ssdna.design.find_missing` + `find_invalid`，
  只读权威的 `config/design_config.yaml`；
- 相应测试从 `params` 那份 json 迁移到 `config` 那份 yaml。

`boundary_count` 原本是写了没人读的死配置——现在会读并校验（环状=2、线性=1）；
`three_prime_modification` / `nick_overrides` 补进配置模板注释。

## 四、仍然欠的债（未在本轮处理）

1. **两套 staple 构造逻辑仍未合并**（`mapping.plan_assembly` vs `design.design_staples`）。
   本次把它们的**行为对齐**了（domain_order、junction、尾巴策略、nick 3′-OH、跨原点重叠），
   但没有合并成单一实现——这是结构性重构，需要更谨慎地做。
2. `Segment.wraps`（`end < start`）与 `BindingSite.wraps`（`end > length`）两套坐标语义并存，
   只在注释里声明，无运行时转换。属于历史包袱，合并两套引擎时一并统一。
3. `tm_nn` 未处理自互补（回文）臂，约 1–2 °C 偏差；本项目只用同批横向比较，影响有限，已在文档注明。
4. `snapgene_raw` 引物序列只来自内置解析器；Biopython 回贴位点是 derived，两者语义不同（已标 origin）。
5. `io.load_snapgene` 的宽 `except Exception` 会把解析器内部 bug 当"Biopython 失败"静默回退——建议收窄。
